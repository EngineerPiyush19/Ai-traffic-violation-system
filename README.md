# AI Traffic Violation System

## Problem
Fixed-timer traffic lights cause congestion and cannot adapt to traffic flow.

## Solution
A DQN-based adaptive traffic signal controller integrated with YOLO vehicle detection and automatic violation monitoring.

## Features
- Adaptive signal control using DQN
- Vehicle detection with YOLOv8
- License plate recognition
- Red-light violation detection
- Traffic analytics
- Hindsight memory architecture

## Tech Stack
- Python
- PyTorch
- YOLOv8
- OpenCV
- SUMO
- TraCI
