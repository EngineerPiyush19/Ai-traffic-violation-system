# AI Traffic Violation System

## Overview

AI Traffic Violation System is a smart-city solution that combines
Reinforcement Learning, Computer Vision, and OCR to improve traffic
management and automatically detect traffic violations.

The system uses:

- YOLOv8 for vehicle detection
- Fast Plate OCR for license plate recognition
- Deep Q-Network (DQN) for adaptive traffic signal control
- OpenCV for image processing
- SUMO for traffic simulation

## Key Features

✅ Adaptive traffic light control

✅ Real-time vehicle detection

✅ Automatic red-light violation detection

✅ License plate recognition

✅ Traffic analytics

✅ Intelligent congestion reduction

## Impact

The system dynamically optimizes signal timings and reduces waiting
times compared to conventional fixed-timer systems.

## Applications

- Smart Cities
- Traffic Law Enforcement
- Urban Planning
- Intelligent Transportation Systems (ITS)
